3. 代跑 `npm start -- --submit`、`npm run submit` 等会改变远端状态的命令；命令只作为索引存在。
4. 未经授权向真实平台发起请求或批量请求，绕过资格审核、访问控制或平台限制。

## 上游原文里的三条关键边界

- **授权**：涉及真实平台的测试要事先取得平台与数据主体的必要授权，遵守法律、平台条款、学校规定与数据处理要求。
